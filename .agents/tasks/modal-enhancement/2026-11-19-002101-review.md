# Enhanced query topic modal with tabs and interactive features

The modal that displays digest query results was restructured from a single scrolling view into a tabbed interface with three sections: Overview, Segments, and Transcript. The Overview tab adds AI-generated summaries, quick stats (segment count, total duration, average relevance), key concepts, and related question suggestions. The Segments tab wraps each segment in an accordion with relevance badges and prominent jump buttons. The Transcript tab adds per-excerpt copy buttons. An action bar at the top provides Copy All and Export (markdown download) functions. Empty states were improved with contextual messaging.

**Watch for:** "Generate Flashcards" button advertised but not implemented (confirmed); related questions filtering may show duplicate queries (likely); export filename sanitization uses basic regex that could produce colliding names (possible).

**Verdict**: CHANGES_REQUESTED

## High-level view

The modal now has three tabs (Overview, Segments, Transcript) controlled by shadcn/ui Tabs, replacing the previous single-scroll layout. Overview generates a text summary from segment and takeaway counts, displays three stat cards (segments, duration, relevance), lists key takeaways, and suggests up to 3 related queries from the `relatedQueries` state. Segments moved into Accordion components with relevance badges, duration labels, and a "Jump to this part" button in each expanded panel. Transcripts gained a copy button that appears on hover. The action bar computes average relevance across segments and provides Copy All (plain text concatenation) and Export (markdown file download). Empty states distinguish "not covered" from "no data" scenarios.

1. **Generate Flashcards advertised but missing** — The task specification lists "Generate Flashcards" as one of three action bar buttons, but only Copy All and Export are implemented. Either add the flashcard generation feature or remove it from the requirements.

2. **Related questions may show current query** — The filter `relatedQueries.filter(q => q !== selectedQuery)` only removes exact string matches. If the user clicks a related question and that query appears again in its own related list (due to backend data), it could show as a suggestion to itself. Add deduplication or verify the backend never returns circular suggestions.

3. **Export filename collisions possible** — `selectedQuery.replace(/[^a-z0-9]/gi, '_').toLowerCase()` converts all non-alphanumeric characters to underscores. Queries like "What is AI?" and "What is AI!" produce identical filenames. Consider adding a timestamp or hash suffix, or preserve more characters in the sanitization.

## Tabbed interface replaces flat scroll

The modal's DialogContent gained `overflow-hidden flex flex-col` to host a Tabs component that manages three views. The tab list shows counts for Segments and Transcript (`Segments ({relevantContent.segments.length})`), giving the reviewer a quick sense of data volume before switching tabs.

## Overview tab: generated summary and quick stats

The Overview tab opens with a text summary produced by `generateSummary()`, which branches on whether segments exist: if segments are present, it lists their topics and counts segments and takeaways; otherwise it counts takeaways and transcript excerpts. This is inline string concatenation, not an LLM call—calling it "AI-generated" in the UI is misleading, though not harmful.

Average relevance is `Math.round(sum / length)`, which floors edge cases (e.g., three segments scoring 33%, 33%, 34% report as 33%).

Related questions shows up to three queries from `relatedQueries`, filtered to exclude the current `selectedQuery`, rendered as buttons that call `setSelectedQuery(query)` to swap the modal content. This is a navigation pattern: clicking a related question reloads the modal with new data rather than opening a nested view.

## Segments tab: accordion with relevance badges and jump buttons

Each segment is wrapped in an Accordion (shadcn/ui) with `type="single" collapsible`, meaning only one segment can be expanded at a time. The trigger displays the segment topic, a relevance badge (`{seg.relevance_score}%`), start time, and duration. Expanding reveals the explanation and a "Jump to this part" button that calls `seekTo(seg.start_time, seg.id)` and closes the modal.

Segments that lack an explanation still render the accordion, but the expanded content only shows the jump button. The previous design displayed explanation inline without requiring expansion, so this adds a click for segments where the topic alone isn't sufficient context.

## Transcript tab: hover copy buttons and timestamp navigation

Each transcript excerpt is a card with a timestamp button (clicking seeks to `t.timestamp` and closes the modal) and a copy button that appears on `group-hover`. The copy button uses `navigator.clipboard?.writeText(t.text)` and shows a toast.

## Action bar: Copy All and Export

The action bar sits above the tabs and contains two buttons and an optional relevance badge. Copy All concatenates the selected query, takeaways (if any), segments (if any), and transcripts (if any) into a plain text block with markdown-style headers, then writes it to the clipboard via `navigator.clipboard?.writeText`. Export does the same concatenation but formats it as proper markdown and triggers a download via a temporary blob URL. The downloaded file is named `${selectedQuery.replace(/[^a-z0-9]/gi, '_').toLowerCase()}.md`.

Both functions use optional chaining (`navigator.clipboard?.writeText`), so they fail silently if the clipboard API is unavailable (e.g., in insecure contexts or older browsers). No fallback or error message is provided.

The relevance badge (`{avgRelevance}% relevant`) only appears when `avgRelevance > 0`. If `relevantContent.segments.length === 0`, avgRelevance is 0, so the badge is hidden even if transcripts exist. This creates an asymmetry: transcripts contribute to the content but not to the displayed relevance score.

## Generate Flashcards button missing

The task specification lists three action bar buttons: Copy All, Export Notes, and Generate Flashcards. The implementation includes only the first two. The commit message does not mention flashcards.

## Empty state improvements

The "no content" empty state changed from "No specific content found in the digest for this topic" to "This topic wasn't directly covered in the digest," with a suggestion to "explore other suggested topics or search the full transcript." This is more conversational and actionable.
